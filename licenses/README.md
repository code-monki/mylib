# Third-party license notices (stub)

Distributable source and binary artifacts will bundle third-party components
(Tesseract, Leptonica, OpenCV, Poppler, PDFium, OpenSSL, Boost, etc.) with
varying license obligations.

Repository policy:
- keep upstream license texts under `licenses/` as components are added to
  release artifacts,
- keep a machine-readable third-party bill of materials in CI once dependency
  pinning is implemented,
- keep human-readable attribution pointers in the root `NOTICE` file.
